Two-step sign-in

Signing in will ask for your password and a 6-digit code from an authenticator app on your phone (Google Authenticator, Microsoft Authenticator, 1Password and others), so a stolen password alone does not open the admin.

  1. In the app, add an account and scan this code (or type the key below).
  2. Enter the 6-digit code the app shows.
